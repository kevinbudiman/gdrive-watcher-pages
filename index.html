Google Drive Watcher

Google Drive Watcher is a small, personal, single-user tool that runs on its owner's own computer and monitors the owner's own Google Drive for file changes.

What it does

  • Uses the Google Drive API with read-only access to check the owner's own change feed (changes.list).
  • Writes a local log of detected changes (created, modified, renamed, moved, deleted).
  • Optionally runs a local script when a change is detected.

How data is handled

The tool is used only by its owner, on the owner's own computer, to work with the owner's own Drive. Nothing is shared with or sent to third parties. See the Privacy Policy for details.
