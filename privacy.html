Privacy Policy — Google Drive Watcher

Last updated: 2026-10-17

Google Drive Watcher ("the tool") is a personal, single-user software utility that runs locally on the computer of its owner and monitors the owner's own Google Drive account for file changes.

Who uses it

The tool is used only by its owner (a single individual) on the owner's own computer. It is not offered as a service to other people.

What data it accesses

With the owner's consent, the tool uses the Google Drive API with read-only scope (drive.readonly) to access file metadata and file content in the owner's own Google Drive account.

How the data is used

Access is used solely to detect changes to the owner's own files and to record those changes in a log on the owner's computer, and optionally to run a local script chosen by the owner. The data is never used for advertising, profiling, or any other purpose.

Where data is stored

All data the tool produces (a change log, a small state file, and the OAuth token) is stored locally on the owner's computer. The only network communication is with Google's own APIs. The tool maintains no server and no cloud storage.

Sharing

Data obtained from Google APIs is never sold, rented, transferred, or shared with any third party. It is not used to train machine-learning models.

Google API Services User Data Policy

Google Drive Watcher's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

The owner can revoke the tool's access at any time at myaccount.google.com/permissions. All locally stored data can be deleted at any time by removing the tool's files from the owner's computer.
